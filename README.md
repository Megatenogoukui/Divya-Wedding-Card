# Divya & Niraj wedding invitation

A bilingual, mobile-first digital Maharashtrian wedding patrika. The static site lives in `dist/` and is published to GitHub Pages by the workflow in `.github/workflows/deploy.yml`.

Visit: https://megatenogoukui.github.io/Divya-Wedding-Card/

All wedding details are taken from the family's supplied invitation PDF. No guest list, tracking, or backend is used.
